Verified on 2026-10-21 (Asia/Shanghai), Linux x86_64, Zig 0.17.0.
CPU: 11th Gen Intel(R) Core(TM) i7-11700 @ 2.50GHz. Host: Linux-6.17.0-40-generic-x86_64-with-glibc2.42.

benchmark were explicitly compiled as focused artifacts.

* Atomic prefilter and producer scaling validation (2026-10-21)

This section covers the final implementation; the initial acceptance results and
single-round benchmark above remain historical evidence. The same host, exact
Zig 0.17.0 and ReleaseFast were used. Paired processes inherited affinity 0-7
(eight physical cores), without system-wide changes. The baseline was compiled
from the worktree before runtime changes, including the staged implementation.
Its source snapshot and manifest are under =build/prefilter-comparison/baseline/=
and =baseline-manifest.json=. Both binaries use identical benchmark source;
the initial Git HEAD was not substituted for the current implementation.

** Correctness and implementation checks

- Final Debug/ReleaseFast check/test passed. The routing matrix covers all
  thresholds/output switches and explicit important. Isolated scenarios cover
  concurrent level writers, writers overlapping close, important-only, no
  outputs, and disabled queries before init, after init failure and after close.
- Existing in-flight close, flush barrier, deduplication, output-failure isolation
  and allocation-failure checks still pass. Debug warn and ReleaseFast
  release-only off compile-filter checks passed.
- Each profile passed 16 small benchmark smoke cases (filtered/sync/async/mixed
  with 1/2/4/8 producers). Eight invalid CLI cases were rejected. Each profile
  additionally ran level-race and level-shutdown 20 times each: 80 bounded
  concurrency runs passed in total.
- ReleaseFast ELF inspection confirms one atomic load/bit test and an early
  return before gate access. std.atomic.cache_line is 128 on this target; the
  mask retains 128 bytes and gate begins on the next cache line. A cold-path
  address escape prevents global scalar replacement from removing padding.
  Runtime publication/reclamation retain the existing protocol.

** Threshold investigation and known tradeoff

Initial async/1/payload p99 rose by more than 10% in all three zones, alongside
more accepted records and fewer drops. Seven further pairs for these cases and
filtered/8 (56 runs), using the same capacity-64 binaries, reproduced the async
increase. Higher attempted throughput or fewer drops is not latency improvement.

Artifact-only harness copies then changed ordinary async queue capacity to
262,144 in both snapshots; production code and defaults remain unchanged.
Seven pairs per zone (42 runs) accepted and processed all 200,000 records per
round with no drops. Another 42 runs used the same large-queue binaries limited
to CPU 0. These diagnostic controls neither replace nor enter the primary
capacity-64 results.

| Timezone | Repeat rate ratio | Repeat p99 ratio | Lossless rate ratio | Lossless p99 ratio | One-core p99 ratio |
|--------+--------------+--------------+----------------+----------------+----------------|
| UTC0 | 1.097 | 1.214 | 1.068 | 1.024 | 1.029 |
| CST-8 | 1.095 | 1.187 | 1.066 | 1.022 | 1.025 |
| EST5EDT,M3.2.0,M11.1.0 | 1.377 | 1.466 | 1.303 | 1.104 | 1.076 |

Lossless UTC/fixed-offset p99 increases fell to about 2%, while DST retained
+10.4% (2544 [2519, 2638] ns → 2809 [2790.5, 2870] ns). One-core increases
were 2.5%-7.6%, but accepted throughput ratios were only 0.913-0.988: these
controls also do not improve every metric. The evidence shows sensitivity to
drop composition and concurrent scheduling. Increased queue interaction with a
faster consumer is a possible mechanism, not a profiler-established single
cause. Single-producer async tail regression remains a known tradeoff; this
optimization promises no tail-latency SLA and does not change the queue protocol.

Filtered/8 initially changed p99 from 17 to 21 ns; the independent repeat was
17 to 16 ns, rate ratio 0.984. Disassembly confirms the same filtering-entry
instruction sequence and the same 128-byte filter bitmap address separated
from gate. The initial alert did not reproduce; nanosecond variation is not
attributed to the calendar path.
